# STICKCITY

A choice-driven stickman superhero-city adventure prototype.

This repository is dedicated to STICKCITY. The game is an original, fictional New York-inspired superhero universe with original characters and storylines. Marvel references are limited to commentary/easter-egg-style nods; no unlicensed Marvel art, logos, character likenesses, or copied skins are included.

## Prototype
Open `index.html` in a browser. No build tooling is required.
